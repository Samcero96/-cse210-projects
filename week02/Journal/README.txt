W02 Project: Journal Program

Files:
- Program.cs
- Journal.cs
- Entry.cs
- PromptGenerator.cs

Core features:
- Writes and stores journal entries with the date.
- Displays all entries with date and prompt.
- Randomly selects prompts.
- Saves the journal to a file.
- Loads the journal from a file.

Creativity additions are documented in Program.cs.
